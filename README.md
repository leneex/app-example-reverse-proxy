# Reverse Proxy Example

Example [Vue](https://vuejs.org/) app for testing a reverse proxy. It is a minimal Vite frontend for checking request routing, headers and redirects behind a proxy.

## <a name="dev"></a>Run locally

```bash
# install dependencies
npm install

# run in dev mode with watch
npm run dev

# build for production with minification
npm run build

# preview the build locally
npm run preview
```
